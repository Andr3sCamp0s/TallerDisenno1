# Sus pruebas

En la **etapa 5** se le piden dos pruebas suyas, en un archivo de esta
carpeta:

1. Una que demuestre que registrar la misma entrega dos veces no duplica
   nada, escrita **con dobles del reloj y del repositorio**, sin base de
   datos.
2. Una que demuestre que agregar una entrega a un lote cerrado levanta
   `LoteYaCerrado`.

Las dos tienen que fallar si usted rompe la regla que prueban. Una prueba que
pasa con cualquier implementacion no prueba nada.
